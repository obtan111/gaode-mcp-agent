# 出行通用指南（证件·订票·酒店·防坑·应急）

本文覆盖与目的地无关的通用出行知识，适用于国内自由行的全流程准备。

## 一、证件与预订

- 身份证是刚需：国内火车、酒店、景区实名制全流程使用，出发前确认未过期。
- 学生证/军官证/残疾证：多数景区半价或免票，学生证研究生通常不享优惠。
- 机票比价：同一航班在不同平台价差可达 10-20%，先看航司官网/APP，再用去哪儿、飞猪比价；周二周三出发通常最便宜。
- 火车票技巧：12306 候补下单成功率高于第三方抢票软件；开售即抢（通常提前 15 天）；高铁无票时可买"全程票"中途下车（票价按全程计）。
- 酒店预订：优先可免费取消的房型；看差评而非好评；连锁酒店在同城 App 上常有会员价；民宿看"真实住客带图评价"超过 20 条的更可信。
- 门票预约：故宫、湖南省博、陕西历史博物馆等热门场馆全部需要提前预约，行前一周列好预约清单。

## 二、行李打包清单

### 证件财务类

- 身份证、学生证等优惠证件、少量现金（200-500 元应急）、手机充电器、充电宝（≤20000mAh，航空限带 2 个）。

### 衣物类

- 按目的地天气准备，遵循"洋葱式穿法"（多层薄衣好增减）；
- 舒适运动鞋（旅行日均步数 1.5-3 万步，新鞋必磨脚）；
- 防晒三件套（帽子/防晒霜 SPF50/墨镜）适用于春夏秋的海边与高原；
- 雨伞或一次性雨衣（山区天气多变）。

### 药品类

- 肠胃药（旅行腹泻高发）、感冒药、创可贴、晕车药、藿香正气水（夏季中暑）；
- 慢性病患者随身携带足量处方药。

### 电子类

- 充电宝、备用数据线、耳机；摄影爱好者带相机时注意镜头防潮。

## 三、酒店选择要点

1. 位置优先于档次：选地铁站 500 米内或核心商圈，省下的通勤时间价值远超房价差。
2. 看差评关键词："隔音差""卫生问题""照片与实际不符"是硬伤，一票否决。
3. 新开业酒店性价比高（设施新、评分往往虚高前 3 个月但硬件确实好）。
4. 景区内酒店贵但省交通时间（如鼓浪屿、黄山山上），权衡行程安排。
5. 入住先检查：床品有无毛发、热水水温、空调制冷、门锁反锁功能。

## 四、防骗避坑清单

- "一日游"低价团：明显低于市场价的团必有购物环节，认准正规旅行社与合同。
- 景区门口"带路党/免排队"：正规预约渠道都能自己搞定，付费带进是骗局。
- 玉器/茶叶/药材店"老乡套路"：导购认老乡、标价虚高十倍再打折，不买。
- 拍照收费：景区穿民族服饰合影、扮铜人合影，拍前必问价。
- 出租车不打表、绕路：用网约车平台（路线与价格透明）。
- "宝石/古董捡漏"：全是剧本，一分钱都别掏。
- 海鲜排档"时价"刺客：点单前确认单价与重量，要求当面称重。

## 五、应急处理

### 证件丢失

1. 立即到当地派出所报案并开具身份证明（凭证明可入住酒店、乘车）；
2. 机场/火车站均有公安制证窗口，可办临时身份证明（当场出证）；
3. 返程后补办身份证，急用可办加急。

### 身体不适

- 轻症：药店对症购药，多喝水休息；
- 急症：拨 120 或用地图搜最近三甲医院；异地就医记得保留票据（医保异地结算需备案，可在"国家医保服务平台"APP 提前备案）。

### 财务问题

- 现金丢了靠手机支付兜底；手机丢了是最麻烦的场景：
- 立即用他人手机挂失 SIM 卡（运营商客服）、冻结支付（微信 95017 / 支付宝 95188）、改密账号密码。

### 天气/灾害

- 出行前 3 天关注目的地天气预警；台风/暴雨红色预警时景区会关闭，行程可免费改期；
- 恶劣天气优先改室内场馆（博物馆/商场），不冒雨登山。

## 六、实用 APP 清单

| 场景 | 推荐 |
| ---- | ---- |
| 交通 | 12306（火车）、航司官方 APP（机票）、当地地铁 APP 或交通码 |
| 住宿 | 携程/美团/飞猪比价，连锁酒店官方 APP 会员价 |
| 导航 | 高德地图（城市公交方案优秀） |
| 门票预约 | 各场馆官方公众号（唯一正规渠道）、美团/大众点评 |
| 攻略 | 马蜂窝（行程）、大众点评（美食，看差评最真实） |
| 应急 | 国家医保服务平台（异地备案）、航司 APP（值机改签） |
