# Python 学习路线指南（从零到就业）

## 一、学习总原则

- 目标驱动：Python 方向太多（Web/数据/自动化/AI），先定方向再学，避免"什么都学什么都不精"。
- 项目驱动：每学完一个阶段必须做一个完整小项目，看视频≠会写代码。
- 时长预期：每天 1-2 小时，零基础到能独立开发小项目约 3-4 个月。

## 二、阶段一：基础语法（2-4 周）

### 学习内容

- 环境安装：Python 3.11+ 与 VS Code（装 Python 扩展）、或 PyCharm 社区版。
- 核心语法：变量与类型（int/float/str/bool）、列表、字典、元组、集合；条件分支（if/elif/else）、循环（for/while）、函数（参数/返回值/作用域）、文件读写（open/with）、异常处理（try/except/finally）。
- 面向对象入门：类、`__init__`、实例方法、继承——写大项目的地基，不需要学多深但要会用。

### 推荐资源

- 入门书：《Python 编程：从入门到实践》前 11 章（最友好的零基础书）。
- 互动练习：Codewars（简单级刷 30 题）或洛谷入门题。
- 视频：B 站任意播放量高的零基础课程（选一个跟完，别反复换）。

### 检验项目

- 命令行记账本：增删改查消费记录，数据存 JSON 文件。
- 批量文件重命名工具：按规则重命名文件夹内所有文件。

## 三、阶段二：标准库与工程化（3-4 周）

### 学习内容

- 常用标准库：os/pathlib（文件路径）、datetime（时间处理）、json/csv（数据交换）、re（正则表达式）、collections（defaultdict/Counter）。
- 虚拟环境：venv 或 conda 的创建与使用（每个项目独立环境，必须养成习惯）。
- 包管理：pip 安装/卸载、requirements.txt 导出。
- 代码规范：PEP8 基本约定、使用 ruff 或 black 自动格式化。
- Git 基础：init/add/commit/push/pull，注册 GitHub 并把每个练习项目推上去（这就是求职作品集）。

### 检验项目

- 爬取天气数据存 CSV 并按周统计（requests + csv + re 综合练习）。
- 把阶段一所有练习整理成规范 GitHub 仓库（含 README）。

## 四、阶段三：方向选择（4-8 周，选一条深入）

### 方向 A：Web 开发（就业岗位最多）

- 学 FastAPI（现代、类型友好、学习曲线平缓）：路由、请求/响应模型（pydantic）、依赖注入、数据库（SQLAlchemy 或直接 SQL）。
- 项目：个人博客系统（文章 CRUD + 用户登录）或待办事项 API + 简单前端页面。

### 方向 B：数据分析

- 学 pandas（数据处理核心）、matplotlib/pyecharts（可视化）、numpy（数值计算）。
- 项目：拿公开数据集（天池/Kaggle）做完整分析报告——数据清洗→分析→可视化→结论。

### 方向 C：自动化办公（最快见效）

- 学 openpyxl（Excel）、python-docx（Word）、selenium/playwright（浏览器自动化）。
- 项目：Excel 批量报表合并工具、自动填报表脚本——解决真实工作问题最有成就感。

### 方向 D：AI 应用开发（当前最热）

- 前置要求：已完成阶段一、二。
- 学 langchain/langgraph 框架、Embedding 与向量检索（RAG）、主流模型 API 调用。
- 项目：做一个带知识库的问答助手（RAG 流程：文档切分→向量化→检索→生成）。

## 五、阶段四：实战与求职（持续）

- 做 1-2 个"解决真实问题"的项目放进 GitHub，README 写清楚背景/用法/技术点。
- 简历上项目描述用 STAR 法：背景→任务→做法（技术选型理由）→结果（量化）。
- 面试高频基础：数据结构（列表/字典底层原理）、GIL 与多线程、装饰器、生成器、深浅拷贝。
- 刷题：LeetCode 简单+中等共 100 题（面试白板题水平足够）。

## 六、常见误区

1. 只看视频不动手：看懂和写出来是两回事，代码必须一行行自己敲。
2. 追新教程反复入门：语法阶段结束后立刻进方向，不要无限刷"从零开始"。
3. 收藏等于学会：收藏夹吃灰没有意义，跟完一个资源再换。
4. 过早纠结框架选型：初学者阶段"能跑起来"比"架构优雅"重要一百倍。
5. 不用版本控制：Git 从阶段二就用起来，求职时 GitHub 空空如也是最减分的项。
